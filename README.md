## 🇬🇧 English Section

### 📌 About the Project
A smart and lightweight library management system developed in Python. This application streamlines the process of managing book inventories, tracking users, and handling support tickets, providing an all-in-one solution for small to medium-scale libraries.

### 🚀 Key Features
*   **Book & Inventory Management:** Structured tracking of books, categories, and availability.
*   **User Management:** Handles user registration and profiling efficiently.
*   **Ticketing System:** Built-in support module (`tickets`) allowing users to submit requests or report issues.
*   **Broadcast Messaging:** A unique `broadcast` feature to send announcements and updates to all registered users.
*   **Data Export & Logging:** Supports data operations using Excel (`.xlsx`) and logs system activities.

### 🛠️ Tech Stack
*   **Language:** Python (Modular design: `main`, `menu`, `defs`)
*   **Database:** JSON for fast, local, and structured data storage
*   **Data Handling:** Excel (XLS/XLSX) integration

## 🇮🇷 بخش فارسی

### 📌 درباره پروژه
یک سیستم مدیریت کتابخانه هوشمند و سبک که با زبان پایتون توسعه یافته است. این برنامه فرآیند مدیریت موجودی کتاب‌ها، اطلاعات کاربران و پشتیبانی را یکپارچه کرده و یک راهکار جامع برای کتابخانه‌ها ارائه می‌دهد.

### 🚀 ویژگی‌های کلیدی
*   **مدیریت کتاب‌ها و موجودی:** پیگیری و ثبت ساختاریافته‌ی کتاب‌ها و وضعیت امانت آن‌ها.
*   **مدیریت کاربران:** ثبت‌نام، پروفایل‌بندی و مدیریت یکپارچه‌ی اعضا.
*   **سیستم تیکتینگ:** دارای ماژول پشتیبانی داخلی برای ارسال درخواست‌ها و گزارش مشکلات توسط کاربران.
*   **ارسال پیام همگانی (Broadcast):** قابلیت ویژه برای ارسال اطلاعیه‌ها و پیام‌های گروهی به تمام اعضای کتابخانه.
*   **پشتیبانی از اکسل و سیستم لاگ:** امکان خروجی/ورودی داده‌ها با فرمت اکسل و ثبت رویدادهای سیستم.

### 🛠️ تکنولوژی‌های استفاده شده
*   **زبان برنامه‌نویسی:** پایتون (طراحی ماژولار)
*   **پایگاه داده:** استفاده از فایل‌های JSON برای ذخیره‌سازی محلی و سریع
*   **مدیریت داده‌ها:** ادغام با فایل‌های اکسل (Excel)
